# Mood board (alrededor de la web)

Una mesa de trabajo de 3000 × 2000 px con todo lo que hemos hecho:

1. **La web**: capturas de Archivo y Archivo en vivo (portada, obras, proceso, contacto).
2. **Tipografía**: Arimo, UnifrakturMaguntia, Unbounded, Bricolage Grotesque, IBM Plex Mono.
3. **Texturas**: trama de 1 bit, texto cortado en bandas, pintura rosa, tinta sola.
4. **Color**: la paleta de la guía y la proporción 70 / 22 / 6 / 2.
5. **Obras + la web en el teléfono**.
6. **Flyers**: los 4 de `08-flyers/`.
Abajo: las palabras clave (gesto → caos → añoranza; gasa, malla, imperdibles…) y las referencias.

## Archivos
- `moodboard_patricia.svg`: **Illustrator** (Archivo → Abrir). El texto se edita; cada bloque es un grupo con nombre (WEB_CAPTURAS, TIPOGRAFIA, TEXTURAS, COLOR…). Guárdalo como .ai.
- `moodboard_patricia.psd`: **Photoshop**, una capa por bloque (el texto viene en píxeles).
- `moodboard_patricia.png`: vista previa.
- `capturas/`: las capturas de la web, sueltas.

Instala antes las fonts de `../08-flyers/fonts/`.
Para regenerarlo: `python3 build_moodboard.py` (si cambia la web, vuelve a sacar las capturas).
